SASS/SCSS Library (Work in Progress)

Started on May 7, 2026, during my DWWM (Web and Mobile Web Developer) training. Beginner in HTML/CSS/JS.

Developed in part with the support of my instructor and AI assistants (Claude and Gemini).

The use of AI is specified in the relevant files. I regularly use AI to help solve complex problems related to mixins.

The design reflects my own vision of the style guide (excluding elements I haven't covered yet, which are noted in the specific documents).

Implementation of an expanded color palette to help color-blind users maintain logical consistency in their choice of gradients.

Ongoing project to implement a comprehensive font-family selection system.

Mixins are currently split between _mixins.scss and various other files. This architecture will be consolidated in upcoming updates.


A script_js directory is provided, containing a file with all the project's JS scripts. 
You will also find a Tuto_us_html directory with several files showcasing the library's practical implementation.
